# AI 协作与迭代记录

本文记录本项目的 AI 辅助开发过程，配合 `SPEC.md` 与 `docs/REPORT.docx` 使用。记录来自本次开发会话的实际指令、审查动作与验证输出，不把 AI 生成内容直接当作验收结果。

## 1. 协作方式

- AI 工具：DeepSeek Harness（DSH）内置编码代理。
- 人（项目负责人）负责：提出需求、确认车辆业务语义、判断版式 / 交互、决定是否上传。
- AI 负责：读取仓库、检索资料、生成候选实现、运行浏览器验证、整理文档。
- 每次修改后由 AI 执行页面加载、控制台检查、接口调用和截图；人工确认视觉与业务含义。

## 3. 关键迭代

### 迭代 1：从业务语义切换到车辆语义

提示词（摘录）：

> “按照昨天已经修改好的基础上进行修改，从参考项目切换到车辆检测，对话在‘平台服务管理项目数据库创建’中。”

处理：

- 复核 8765 旧代码与参考版相似度，发现核心 JS 约 99% 同源；
- 新建车辆场景 `yard.svg`，类别改为 `car / truck / van`；
- 项目、任务、复核、报告、AI 提示词全部改为车辆语义；
- 保留 `platform-service-db` 的数据库设计资料，不把服务管理表误当成车辆检测表。

验证：项目页 9 个车辆候选，复核列表显示 truck / car / van。

### 迭代 2：独立重写与反抄袭审查

提示词（摘录）：

> “代码不能与前网页相同或者雷同，必须体现出差异性，不能被认为有抄袭嫌疑。”

处理：

- 对比 `frontend` 与参考项目备份的逐文件相似度；
- 不在旧代码上继续换皮，改为 `frontend-v2` 独立架构；
- 重新编写 HTML / CSS / 状态管理 / Canvas 绘制 / 检测页；
- 保留业务概念（项目、任务、复核、区域计数）但更换实现与命名。

审查证据：旧 `app.js` 99.0%、`detect.js` 98.8%、`motion.js` 100% 与参考版相似；新版为独立文件与数据。

### 迭代 3：动效设计

提示词（摘录）：

> “保留昨天的动画设计。”
>
> “采用 https://sibaldesign.com/ 中的动画效果。”

处理：

- 参考 sibaldesign 的启动计数、描边大数字、SKIP INTRO、HUD 网格与滚动节奏；
- 在保持纸面 / 墨色视觉的前提下实现：启动序列、rail ink 滑条、错峰入场、数字计数、详情 flash、检测扫描线、计数 bump、ticker、自定义光标、磁吸按钮、滚动 reveal；
- 加 `prefers-reduced-motion` 降级。

验证：启动序列显示 02/05，rail 滑条随模块移动，检测扫描线在 `#lab-stage.scanning` 时出现。

### 迭代 4：使用说明排版修复

提示词（摘录）：

> “使用说明部分排版是乱的，进行修改。”

定位：滚动显现类 `.reveal` 与登录密码显示按钮 `.reveal` 同名，导致说明章节 `position:absolute` 全部叠在页头。

修复：

- 滚动显现改名为 `.scroll-reveal`；
- 说明页标题缩短为“九模块 · 一条线”；
- 正文最大宽度限制；
- 移动端 rail 设 `min-width:0`，消除 825px 横向溢出；
- 当前模块自动滚动到可见位置。

验证：1440 / 1026 / 390 三档截图，无重叠、无横向滚动条。

### 迭代 5：接入原有模型

提示词（摘录）：

> “接入原有模型。”

处理：

- 新增 `model.js`，按原契约请求 `POST /api/v1/vision/sessions` 与 `/vision/detect`；
- 请求携带当前帧 `image.data_url`，把 `detections[].polygon` 映射到画布；
- 服务不可达时不伪造结果，标记 `LOCAL / MOCK` 并回退 `scene.js`；
- 用接口桩验证：`MODEL / HTTP`，返回 1 个 `truck`，画布与列表同步。

## 3. 对 AI 生成代码的审查

| 风险 | 审查动作 | 处理 |
|---|---|---|
| 直接换皮旧代码 | 逐文件相似度 + 备份比对 | 改为独立重写 |
| 误用旧版字段 | 检查 label / contract / 项目名 | 全部车辆化 |
| CSS 类名冲突 | 浏览器计算样式定位 | `.reveal` → `.scroll-reveal` |
| 移动端横向溢出 | `scrollWidth` 与元素边界检查 | rail `min-width:0` |
| 模型失败伪造成果 | 断网 / 桩接口测试 | 明确 `LOCAL / MOCK` 回退 |
| API 非法状态 | 422 测试 | 后端 CHECK + 422 |
| 版本未持久化 | SQLite 查询 | `versions` / `version_items` 快照 |

## 5. 人机边界

- AI 不替代业务判断：车辆类别、区域计数规则、模型可信度由人确认。
- AI 不替代验收：所有数字来自实际页面 / API / SQLite 查询。
- 不把 mock 结果标成真实模型推理；不把参考结果改标签后当作车辆模型结果。
- 不自动上传 GitHub 或合并分支；发布由人执行。
